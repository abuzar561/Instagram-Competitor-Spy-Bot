# Workflow Template

`instagram-spy-google-sheets.json` is a sanitized n8n workflow template for public repository use.

## Before Activating

1. Import the JSON file into n8n.
2. Connect Google Sheets credentials in `Log Post Snapshot`.
3. Replace `YOUR_GOOGLE_SHEET_ID` with your spreadsheet ID.
4. Create or select a tab named `Instagram Spy`.
5. Connect Discord credentials in `Send Discord Alert`.
6. Activate the workflow and copy the production webhook URL.

The template does not include credentials, webhook IDs, private sheet URLs, Discord webhook URLs, or instance metadata.
